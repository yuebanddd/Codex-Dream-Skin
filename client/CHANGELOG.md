# Changelog

## 0.2.0 — 2026-07-16

- 产品正式命名为 LumaDrobe，并完成桌面应用、包名和界面品牌替换
- 新增 Rust 本地主题安装服务和持久化安装目录
- 对图片进行体积与文件签名校验，仅接受 PNG、JPEG 和 WebP
- 对 CSS 进行 UTF-8、体积、远程资源、`@import` 和危险协议检查
- 为每个落盘资源记录 SHA-256，安装过程先写临时目录再切换
- 新增安装状态、下载并安装、更新清理和安全删除界面交互
- 已安装主题可在取消订阅后继续离线显示
- 拒绝 `.` 与 `..` 作为订阅源、主题或版本的存储路径组件
- 按主题版本区分“已安装”和“可更新”，允许安全升级到新版本
- 版本升级至 0.2.0

## 0.1.0 — 2026-07-16

- 建立 Tauri 2 + React + Rust 跨平台桌面客户端
- 按“深色侧栏、主题衣橱、右侧试衣镜”产品形态实现首版界面
- 支持添加、刷新和删除公开 GitHub 仓库订阅源
- 支持通过 `?ref=` 指定分支、标签或提交
- 实现 Dream Skin Git Repository Source Protocol v1
- 使用原子 JSON 文件缓存订阅源和皮肤目录
- 在当前仓库加入可直接订阅的示例源清单
- 预留本地安装、导出、应用、恢复和 Rust CDP 引擎入口
