# Changelog

## 0.5.1 — 2026-07-17

- Windows 渲染页在每次连接后先启用 Runtime 与 Page 域，再在同一 CDP 会话内完成 DOM 校验与主题注入
- `Runtime.evaluate` 使用独立 30 秒时限，错误包含命令、目标 ID 与载荷大小
- 新增 1 MiB 滚动 JSONL 运行日志，Unix 权限固定为 `0600`，诊断页直接展示日志路径
- PR 阶段汇总并复验三个平台的发布资产，合并到 `release` 后才自动创建唯一版本号的 Pre-release
- GitHub Actions 不使用 npm 依赖缓存
- 版本升级至 0.5.1

## 0.5.0 — 2026-07-17

- 新增 macOS arm64/x64 DMG 与 Windows x64 NSIS 测试安装包工作流
- 每个安装包产物附带 `BUILD-INFO.json` 和 `SHA256SUMS.txt`
- 构建元数据记录版本、提交、平台、架构、大小与 SHA-256
- 新增跨 package、Tauri 与 Cargo 配置的版本一致性检查
- 客户端诊断信息增加构建提交，并支持显式导出 JSON
- 测试安装包保持无签名，不自动创建 GitHub Release
- 版本升级至 0.5.0

## 0.4.0 — 2026-07-17

- 新增不退出 Codex 的皮肤暂停与恢复，暂停状态跨 LumaDrobe 重启持久化
- 暂停时等待自动重注入 watcher 完整退出后再移除主题，避免并发重注入
- 恢复皮肤失败时回滚到持久化暂停状态，避免产生无人管理的注入会话
- 新增只读运行诊断页，检查官方安装、进程、监听身份、CDP 会话和 Codex 渲染页
- 诊断信息展示客户端与 Codex 版本、平台架构、会话记录和可执行文件路径
- 暂停中的主题继续受到更新与删除保护
- 版本升级至 0.4.0

## 0.3.0 — 2026-07-16

- 新增 Rust Codex 发现服务，校验 macOS Bundle ID、代码签名团队与 Windows Store 包身份
- 新增严格回环 CDP 客户端，拒绝非 loopback、错端口、带凭据或异常路径的 WebSocket URL
- 启动前验证 CDP 监听进程属于官方 Codex，并以浏览器 ID 锚定会话身份
- 仅向通过 `app://` 与 Codex DOM 标记双重验证的渲染页注入主题
- 从已安装主题生成内置 Renderer Payload，不允许订阅源提供 JavaScript
- 注入前重新校验本地图片和 CSS 的路径、体积与 SHA-256，拒绝安装后篡改
- 新增“应用并启动”、会话内热切换、Renderer 重载自动重注入
- 新增运行状态持久化与客户端重启恢复监护
- 新增“恢复原生并重启”，先验证保存的应用、端口与浏览器身份再操作进程
- 运行中的主题不可删除，避免本地状态与活动会话分叉
- 版本升级至 0.3.0

## 0.2.0 — 2026-07-16

- 产品正式命名为 LumaDrobe，并完成桌面应用、包名和界面品牌替换
- 新增 Rust 本地主题安装服务和持久化安装目录
- 对图片进行体积与文件签名校验，仅接受 PNG、JPEG 和 WebP
- 对 CSS 进行 UTF-8、体积、远程资源、`@import` 和危险协议检查
- 为每个落盘资源记录 SHA-256，安装过程先写临时目录再切换
- 新增安装状态、下载并安装、更新清理和安全删除界面交互
- 已安装主题可在取消订阅后继续离线显示
- 拒绝 `.` 与 `..` 作为订阅源、主题或版本的存储路径组件
- 按主题版本区分“已安装”和“可更新”，允许安全升级到新版本
- 解码 CSS 转义后再执行安全检查，阻止转义形式的远程导入
- 已安装主题优先使用本地资源，保持订阅时也可离线预览
- Windows 使用可覆盖目标的原子文件替换，确保重复安装和删除可持久化
- CSS 安全检查同时归一化注释与 `url()` 空白，阻止协议相对远程资源
- 逐块读取主题资源并在超限时立即中止，避免无长度响应导致过量内存占用
- 阻止所有 `file:` URL 形式访问本地文件
- 版本升级至 0.2.0

## 0.1.0 — 2026-07-16

- 建立 Tauri 2 + React + Rust 跨平台桌面客户端
- 按“深色侧栏、主题衣橱、右侧试衣镜”产品形态实现首版界面
- 支持添加、刷新和删除公开 GitHub 仓库订阅源
- 支持通过 `?ref=` 指定分支、标签或提交
- 实现 Dream Skin Git Repository Source Protocol v1
- 使用原子 JSON 文件缓存订阅源和皮肤目录
- 在当前仓库加入可直接订阅的示例源清单
- 预留本地安装、导出、应用、恢复和 Rust CDP 引擎入口
